# Contributing to wiki2gaz-modern

Thank you for your interest in contributing! Please adhere to the following guidelines:

1.  **Code Style:** Follow the standards outlined in `docs/pkia_coding_standards.md` (Black, Flake8, MyPy, Google-style docstrings).
2.  **Testing:** Include relevant unit or integration tests for any new features or bug fixes. Ensure all tests pass (`poetry run pytest`).
3.  **Documentation:** Update relevant documentation (README, docstrings, `/docs` files) for any changes.
4.  **Pull Requests:** Submit changes via Pull Requests. Ensure PRs are focused on a single issue or feature. Provide a clear description of the changes. Require at least one review.
5.  **Issue Tracker:** Check the project's issue tracker for existing bugs or feature requests before starting work.
