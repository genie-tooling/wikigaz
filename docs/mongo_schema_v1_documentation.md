# MongoDB Schema Documentation: wikidata_entities_v1

**Version:** 1.0
**Date:** 2025-04-14
**Author:** Data Architect (Knowledge Graph Architect & Modernization Strategist)
**Collection Name:** `wikidata_entities_v1` (Configurable via `mongodb.collection_entities`)
**Schema File:** `config/mongo_schema_v1.json`

## Introduction

This document provides detailed explanations for the schema applied to documents in the MongoDB collection populated by the `wiki2gaz-modern` pipeline. The schema enforces structure and data types for entities ingested from Wikidata and enriched with Wikipedia signals. It is designed to support downstream applications like RAG by providing relevant, structured information about entities.

The schema is applied using MongoDB's `$jsonSchema` validation feature during the `Setup Database` pipeline step (`scripts/setup_mongodb.py`).

**Primary Key:** The document's `_id` field is the Wikidata QID (e.g., "Q60").

## Top-Level Fields

### `_id`
*   **Type:** `string`
*   **Description:** The Wikidata QID (e.g., "Q60"). Used as the immutable primary key for the MongoDB document. Ensures uniqueness.
*   **Required:** Yes
*   **Source:** Wikidata item `id` field.

### `wikidata_id`
*   **Type:** `string`
*   **Description:** Redundant storage of the Wikidata QID (`_id`). Included for potential query convenience or compatibility with tools that prefer explicitly named ID fields.
*   **Required:** Yes
*   **Source:** Wikidata item `id` field.

### `english_label`
*   **Type:** `string`
*   **Description:** The primary English label for the entity, intended for display and identification.
*   **Required:** No (Schema allows null/missing, but typically present for filtered entities).
*   **Source:** Wikidata item's `labels.en.value`.

### `english_description`
*   **Type:** `string`
*   **Description:** The English description providing brief context about the entity. Useful for disambiguation and understanding.
*   **Required:** No
*   **Source:** Wikidata item's `descriptions.en.value`.

### `aliases`
*   **Type:** `object`
*   **Description:** Contains alternative names (aliases) for the entity, grouped by 2/3-letter language code (e.g., 'en', 'fr', 'es'). Aliases from regional variants (e.g., 'en-gb', 'en-ca') are merged into the base language code ('en'). Lists within each language code contain unique, non-empty string values, sorted alphabetically. Useful for matching variations in user queries or text.
*   **Required:** No (Will be an empty object `{}` if no aliases exist).
*   **Source:** Wikidata item's `aliases` field. Processed by `utils.wikidata_helpers.extract_aliases`.
*   **Structure Example (`aliases`):** `{"en": ["NYC", "New York"], "es": ["Nueva York"]}`

### `instance_of`
*   **Type:** `array` of `string`
*   **Description:** A list of Wikidata QIDs representing the "instance of" (P31) relationships for this entity (e.g., `["Q515"]` for a city). Essential for understanding the entity's type.
*   **Required:** Yes (as per schema definition, will be `[]` if entity has no P31 claims).
*   **Source:** Wikidata claims for Property P31. Values are the QIDs from the claim's datavalue.

### `corrected_class`
*   **Type:** `string` or `null`
*   **Description:** A single, representative class QID assigned based on the configured semantic correction strategy (typically "most_specific_known" using `config/class_mapping_rules.yaml`). This aims to provide a primary, stable type identifier for filtering or categorization. Remains `null` if no P31 value matches the rules or if the `instance_of` array is empty.
*   **Required:** No (Field may be absent or null before correction step runs).
*   **Source:** Generated by `scripts/apply_semantic_corrections.py`.

### `coordinates`
*   **Type:** `object` (GeoJSON Point)
*   **Description:** GeoJSON Point representation of the entity's primary coordinate location (derived from P625 claims). Includes 'type': "Point" and 'coordinates': [\`longitude\`, \`latitude\`] array. Essential for geospatial queries. MongoDB's `2dsphere` index is typically created on this field.
*   **Required:** Yes (as per schema definition; typically enforced by ingestion filter `require_coordinates: true`).
*   **Source:** Wikidata claims for Property P625. Extracted by `utils.wikidata_helpers.extract_coordinates`.
*   **Structure:** `{ "type": "Point", "coordinates": [-74.006, 40.7128] }`

### `country_membership`
*   **Type:** `array` of `object`
*   **Description:** Lists historical country memberships derived from P17 (country) claims. Each object includes the `country_qid` and optionally the `start_year` (from P580 qualifier) and `end_year` (from P582 qualifier) of that membership period. Allows tracking historical political geography.
*   **Required:** No (Will be `[]` if no P17 claims).
*   **Source:** Wikidata claims for Property P17 and its P580/P582 qualifiers. Extracted by `utils.wikidata_helpers.extract_complex_property`.
*   **Object Structure:** `{ "country_qid": "Q30", "start_year": 1776, "end_year": null }`

### `admin_hierarchy`
*   **Type:** `array` of `object`
*   **Description:** An ordered list representing the administrative hierarchy derived by traversing P131 (located in admin entity) claims upwards from the current entity. Level 0 is the most specific direct parent found via P131. Includes the QID, hierarchy `level` (integer), and the `label` (English label preferred, fallback to QID) of the administrative entity at that level. This structure may be modified by the ontology fix script (`scripts/fix_ontology_mongo.py`) to remove intermediate "sub-part" levels based on configuration.
*   **Required:** No (Will be `[]` if no P131 claims or traversal fails).
*   **Source:** Generated by `utils.wikidata_helpers.extract_admin_hierarchy`. Potentially modified by `scripts/fix_ontology_mongo.py`.
*   **Object Structure:** `{ "qid": "Q1384", "level": 0, "label": "New York State" }`

### `population`
*   **Type:** `array` of `object`
*   **Description:** Contains population figures derived from P1082 claims. Each object includes the population `value` (as a 64-bit integer/`long`) and the `point_in_time` (from P585 qualifier) stored as a BSON Date object if parsable, otherwise the raw Wikidata time string is stored. Allows tracking population over time.
*   **Required:** No (Will be `[]` if no P1082 claims).
*   **Source:** Wikidata claims for Property P1082 and its P585 qualifier. Extracted by `utils.wikidata_helpers.extract_complex_property`.
*   **Object Structure:** `{ "value": 8537673, "point_in_time": ISODate("2016-01-01T00:00:00Z") }` or `{ "value": 8000000, "point_in_time": "+2015-00-00T00:00:00Z" }`

### `area_sqkm`
*   **Type:** `double` or `null`
*   **Description:** The area of the entity, derived from P2046 claims and converted to square kilometers. Currently prioritizes values explicitly stated with unit Q712226 (square kilometer). May be `null` if no P2046 claim exists, the unit is not sqkm (and conversion is not implemented), or parsing fails.
*   **Required:** No
*   **Source:** Wikidata claims for Property P2046. Extracted/Converted by `utils.wikidata_helpers.extract_complex_property`.

### `dates`
*   **Type:** `object`
*   **Description:** Contains key lifecycle dates associated with the entity, stored as years.
*   **Required:** No (Object may be absent if neither date is found).
*   **Source:** Extracted by `utils.wikidata_helpers.extract_complex_property`.
*   **Structure:**
    *   `inception_year`: (`int` or `null`) - Earliest year derived from P571 (inception) claims.
    *   `dissolved_year`: (`int` or `null`) - Earliest year derived from P576 (dissolved/abolished) claims.

### `wiki_links`
*   **Type:** `object` or `null`
*   **Description:** Contains data derived from processing incoming links from English Wikipedia pages pointing to this entity's corresponding Wikipedia page (identified via sitelink and Wikimapper). Provides signals about the entity's prominence and common references within Wikipedia. Null if Wikipedia processing is disabled or no links/mentions are found.
*   **Required:** No
*   **Source:** Generated by `scripts/enrich_mongo_with_wiki.py` based on output from `scripts/process_wiki_stats.py`.
*   **Structure:**
    *   `normalized_enwiki_title`: (`string`) - The canonical normalized title of the linked English Wikipedia page. Essential for linking stats correctly. Derived from the Wikidata sitelink `enwiki.title` and normalized using `utils.helpers.normalize_wikipedia_title`.
    *   `inlink_count`: (`int` or `null`) - Total count of incoming links from other English Wikipedia articles to this entity's page.
    *   `top_mentions`: (`array` of `object`) - List of the most frequent anchor texts (mention strings) used in the incoming links. Limited by `enrichment.max_mentions_to_store` config. Object structure: `{ "mention": "string", "count": int }`.

### `ontology_flag_resolved`
*   **Type:** `bool`
*   **Description:** A flag indicating whether this entity has been processed by the specific P131 hierarchy ontology flaw correction logic detailed in `docs/ontology_flaw.md`. Set to `true` after processing by `scripts/fix_ontology_mongo.py`, regardless of whether the hierarchy was actually modified. Useful for tracking processing state and preventing redundant checks. Defaults to `false` conceptually if absent.
*   **Required:** No (Field may be absent before the fix script runs).
*   **Source:** Set by `scripts/fix_ontology_mongo.py`.

### `embedding_vector`
*   **Type:** `binData` or `null` (Schema also allows `array` for flexibility, but `binData` is standard)
*   **Description:** Stores the semantic vector embedding for the entity, if generated by `scripts/generate_embeddings.py`. Stored as **BSON Binary data (subtype 0x00)** derived from a float32 NumPy array. The dimensionality depends on the model used (e.g., 384 for `all-MiniLM-L6-v2`). Null if embeddings are disabled or generation failed for this entity. Useful for semantic search / RAG.
*   **Required:** No
*   **Source:** Generated by `scripts/generate_embeddings.py`.

### `last_updated`
*   **Type:** `date`
*   **Description:** BSON timestamp indicating when this document was last inserted or significantly updated by the `wiki2gaz-modern` ingestion/processing pipeline (specifically, the `ingest_wikidata_mongo.py` script sets this during the `ReplaceOne` operation). Useful for tracking data freshness.
*   **Required:** Yes
*   **Source:** Set automatically by `scripts/ingest_wikidata_mongo.py`.
